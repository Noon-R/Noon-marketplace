# デザインドキュメント テンプレート

新しいテンプレートを `templates/<名前>/` に追加するとき、このひな形をコピーして
`design.md` を作成する。スライド生成時、Claudeはこのドキュメントを読んで
構成・トーン・レイアウト選択を決める。

---

# <テンプレート名> デザインドキュメント

## 用途・対象者

- 想定シーン: （例: 社内提案 / 顧客向け提案 / 技術勉強会 / 経営報告）
- 想定読者: （例: 非エンジニアの意思決定者）
- トーン: （例: フォーマル / カジュアル / データドリブン）

## デッキ構成ルール

- 標準構成: 表紙 → アジェンダ → 本編 → まとめ → Appendix
- 推奨スライド枚数: （例: 本編10枚以内）
- 1スライド1メッセージ。タイトルは結論を書く（体言止め禁止 等）

## レイアウト使い分け

`inspect_template.py` の出力に基づき、どのレイアウトをいつ使うか記述する。

| レイアウト名 | 用途 |
|---|---|
| Title Slide | 表紙のみ |
| Section Header | 章の区切り |
| Title and Content | 標準の本文スライド |
| Two Content | 比較・Before/After |

## テキストルール

- タイトル: 最大○文字、文体（だ・である / です・ます）
- 箇条書き: 1スライド最大○行、1行最大○文字、階層は2段まで
- 禁止事項: （例: 長文の段落、自動配色の上書き）

## ビジュアルルール

- 配色・フォントはスライドマスターに従う（アウトラインで上書きしない）
- 強調色の使い所: （例: 数値ハイライトのみ）
- 図・表の扱い: （例: 表は5行まで、それ以上はAppendixへ）

## 発表者ノート

- ノートを書くか: （例: 全スライドに話す内容の要点を書く / 不要）
