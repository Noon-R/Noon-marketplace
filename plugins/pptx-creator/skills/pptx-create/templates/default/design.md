# default デザインドキュメント

`template.pptx` を持たない組み込みテンプレート。python-pptx 標準のスライドマスターで
生成する。汎用の社内資料・たたき台向け。

## 用途・対象者

- 想定シーン: 社内共有、ドラフト、テンプレート未定の初稿
- トーン: 簡潔・中立。装飾より構成の明快さを優先

## デッキ構成ルール

- 標準構成: 表紙 → アジェンダ → 本編 → まとめ
- 1スライド1メッセージ。タイトルはそのスライドの結論を書く
- 本編は10枚以内を目安。あふれる内容はAppendixへ

## レイアウト使い分け

アウトラインJSONでは `slide_size: "16:9"` を指定すること。
組み込みマスターのレイアウト（インデックス指定可）:

| index | レイアウト名 | 用途 |
|---|---|---|
| 0 | Title Slide | 表紙のみ |
| 1 | Title and Content | 標準の本文スライド |
| 2 | Section Header | 章区切り |
| 3 | Two Content | 比較・対比 |
| 5 | Title Only | 図・表を大きく置くスライド |
| 6 | Blank | 全面図版 |

## テキストルール

- タイトル: 40文字以内
- 箇条書き: 1スライド最大6行、1行40文字以内、階層は2段まで
- 文体: 体言止めまたは「だ・である」で統一

## ビジュアルルール

- 色・フォントの個別指定はしない（マスター任せ）
- 表は5行まで。数値の羅列は表、傾向の主張はグラフ画像
