# Simplify

変更されたコードを自動レビューし、品質・効率性・再利用性の問題を発見して修正します。

## 概要

このスキルは Claude Code の Web セッションで利用可能な組み込みスキルです。
コード変更後に呼び出すことで、変更箇所を中心に品質向上の提案と自動修正を行います。

## ワークフロー

### 1. 変更コードの確認

- 直前のコード変更・追加内容を把握する
- 変更の意図と影響範囲を確認する

### 2. 品質レビュー（3つの観点）

**再利用性**
- 重複コードの検出（DRY原則）
- 共通処理の関数・モジュール化の可能性
- 汎用化できる処理の特定

**品質**
- 命名規則の一貫性と明確さ
- 関数の単一責任原則（SRP）への適合
- エラーハンドリングの妥当性
- 不要なコメント・デッドコードの除去

**効率性**
- 不必要な計算・処理の特定
- データ構造の選択妥当性
- ループ・条件分岐の最適化可能性

### 3. 修正実行

- 発見した問題を優先度順に整理する
- 動作に影響しない安全なリファクタリングを実施する
- 変更内容とその理由を明示する

### 4. 完了確認

- 修正前後の動作同等性を確認する
- 既存テストが通ることを確認する

## 使用例

```
# コード変更後に呼び出す
/simplify

# 特定ファイルを対象に指定する場合
simplify src/utils.py を確認して
```

## 評価サマリー

| 項目 | 評価 |
|------|------|
| 目的の明確さ | ◎ 明確（コード品質改善） |
| トリガーの充実度 | ○ 複数キーワード対応 |
| 適用範囲 | ○ 変更コードに限定（スコープ明確） |
| 自動化レベル | ◎ 発見から修正まで一貫して実行 |
| リスク | △ 動作変更を伴う修正には注意が必要 |

## 注意事項

- このスキルはコードの**動作を変えない**リファクタリングに特化しています
- 機能追加や仕様変更を伴う改善は対象外です
- テストが存在する場合は修正後に必ず実行してください
